# Buku Pupuk

Penulisan ulang aplikasi Android dengan **Flutter + Firebase** berada di [`flutter/`](flutter/README.md). Antarmuka native Dart menggantikan React/WebView, dengan data Firebase lama tetap dapat dibaca.

Kode Android lama tetap tersedia pada riwayat Git sebelum branch penulisan ulang ini. Jangan menghapus data/jurnal aplikasi lama sebelum memastikan seluruh transaksi telah tersinkron dan cadangan tersimpan.

GitHub Actions menguji proyek Flutter dan menghasilkan APK debug untuk pemeriksaan. Pembaruan produksi membutuhkan keystore APK sebelumnya dan pengujian pada perangkat nyata.
